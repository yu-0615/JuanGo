# JuanGo

JuanGo 是一個用 SwiftUI 寫的英文單字複習 App（iOS 26），用間隔複習幫你把單字從「初見」練到「精通」。單字範圍從國小、國中、大考一路到多益、雅思、托福。

## 功能

- **主頁**：每日目標進度環、待複習數、連續天數，一鍵開始今日學習；「我的清單」每列顯示幾個字待複習，點一下就練那個清單，還有自動產生的「最近答錯」（兩週內答錯的字）；今天練完會顯示明天有幾個字要複習；自由練習、學習紀錄（每天練了哪些字，點字看單字頁）
- **例句**：內建字庫中 6,500 多個字附有事先產生的例句和中文翻譯，其餘的由裝置端 Apple Intelligence 在背景補上；例句裡的單字會標出來（片語和變化形也認得，例如 kept the fire alive）。單字頁和字卡背面可以聽整句例句，不喜歡的例句可以「換一句」
- **探索**：左右滑的單字卡，點兩下收進「我的單字」
- **新增**：輸入英文或中文查字；貼上從記事本或聊天複製的單字清單；拍照掃描課本（依句子判斷詞性；拍單字統整頁會直接帶入頁面上的詞性和中文）；從相簿或檔案（txt／csv）匯入
- **AI 翻譯（預設關閉）**：在「設定 › API」打開後，字典沒有的字（查字、掃描、匯入）會翻成詞性＋繁體中文。可填任何 OpenAI 相容的 API（網址、模型、自己的 key），預設是 [Agnes AI](https://platform.agnes-ai.com) 的免費模型；沒有 key 時用裝置上的 Apple Intelligence。關閉時用 Apple 翻譯（較快）
- **字庫**：我的單字、清單（搜尋可用英文或中文，多個字不分順序：keep alive 找得到 keep sth alive；可依「下次複習」排序；掃描造成的重複字會提示合併；清單頁可以直接練習），以及內建字庫（每個字庫都能搜尋，顯示已經加入幾個字，也可以只看未加入的字）：
  - 大考詞彙：基礎 2000、進階 4000、學測 6000+（大考中心 6 級）
  - 國中小 1200：教育部國中小基本字彙
  - 多益 TOEIC、雅思 IELTS、托福 TOEFL
- **練習**：翻卡片、英翻中、中翻英、克漏字、聽力、拼單字；自動安排或手動挑選題型、無盡模式
  - 片語照考試的方式出題：keep sth alive 的克漏字是「____ the project ____」，選項是「keep / alive」這種格式；含 sth／sb 的片語不考拼字
  - 選擇題可以按「不知道」直接看答案（不必用猜的）；干擾選項不會出現第二個正確答案
  - 拼單字直接在字母格裡打字，連字號、撇號這類符號會先給；「提示」會補下一個字母；英式、美式拼法都算對（favour／favor）；拼錯可以「再打一次」照著正確拼法打一遍
  - 聽力題可以「慢速再聽」
  - 結算頁先列出這輪的字（答錯的排最前面），點字可看單字頁，也可以「只練答錯的字」
  - 複習以「天」為單位到期：昨晚練的字，今天早上就會出現在待複習
- **我的**：連續天數、學習日曆（點某一天看那天練了哪些字）、熟練階梯、成就勳章
- **App 捷徑**：對 Siri 說「用 JuanGo 開始今日學習」，或從 Spotlight、捷徑 App、動作按鈕直接開始今天的練習
- **每日提醒**：設定的時間提醒複習，並說今天有幾個字到期；當天已經練過就不提醒
- **備份與分享**：設定 › 備份可匯出／還原全部資料（單字、熟練度、清單、複習紀錄、設定）；清單頁右上角可把清單分享成檔案或 8 碼分享代碼，別人在「新增 › 匯入檔案／輸入分享代碼」加入
- **帳號與同步**：用 Email 連結登入（Supabase），單字和進度自動備份到雲端，換手機登入就回來
- 7 組主題色，頁面底色與區塊跟著主題色調變化，支援深色模式
- 支援 VoiceOver（圖示按鈕、圖表、日曆、勳章都有完整說明）、大字體（輔助使用字級下版面會改成直排）和「減少動態效果」

## 設計

- 介面以原生 SwiftUI 元件為主（List、`.searchable`、Liquid Glass 按鈕），規則寫在 `DESIGN.md`
- 圖示全部使用 Apple 的 SF Symbols

## 專案結構

- `JuanGo/`：App 原始碼。主頁在 `StudyTab.swift`，練習流程拆成 `StudyFlow`（設定）、`SessionEngine`（出題與排程）、`SessionView`、`Questions`（各題型）、`Summary`（結算、學習紀錄）
- `JuanGo/words.json`：內建字典（10,492 個字，含分級、標記、例句）
- `tools/examples/`：在 Mac 上用 Apple Intelligence 批次產生例句的工具，產生後用 `merge.py` 併進 `words.json`；比對單字的 `WordMatch.swift` 和 App 裡的是同一套規則，修改時兩邊要一起改
- `supabase/`：雲端同步的資料表與權限規則

## 安裝

- **自己編譯**：用 Xcode 26 打開 `JuanGo.xcodeproj`，在 Signing & Capabilities 換成自己的 Team，執行到 iPhone 或模擬器。
- **自己簽名安裝 IPA**：下載 Releases 裡的 IPA，用 [Sideloadly](https://sideloadly.io) 或 [AltStore](https://altstore.io) 以自己的 Apple ID 簽名安裝。iPhone 要打開「設定 › 隱私權與安全性 › 開發者模式」，並在「設定 › 一般 › VPN 與裝置管理」信任自己的 Apple ID。免費 Apple ID 簽的 App 每 7 天要重簽一次（資料不會消失）。

需求：iOS 26、Xcode 26。

## 資料來源與授權

- 大考詞彙與分級：大學入學考試中心《高中英文參考詞彙表》（111 學年度起適用），僅供非營利學習使用。
- 國中小 1200：教育部《十二年國民基本教育課程綱要 語文領域－英語文》附錄五表一「基本 1,200 字」。
- 多益：[TOEIC Service List 1.2](https://newgeneralservicelist.com/toeic-service-list)（Browne, C. & Culligan, B.），[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)；`words.json` 中由它而來的 `toeic` 標記同樣以 CC BY-SA 4.0 釋出。
- 雅思、托福字表，以及中文解釋與音標：整理自 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT License），並轉為繁體中文（台灣用語），內容可能有誤。
- 圖示：Apple SF Symbols。
- 學習資料預設只存在自己的裝置上；登入帳號後會同步到 JuanGo 的 Supabase 專案（每個人只能讀寫自己的資料，分享清單只能用代碼取得，資料表與權限規則見 `supabase/schema.sql`）。打開 API 翻譯並設定 key 後，字典沒有的單字會傳到該 API 的伺服器翻譯；key 存在裝置的鑰匙圈，不在程式碼裡。

這是一個高中自主學習專案。
